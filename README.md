 National Population Registration System - Academic Capstone Project 
 Overview 
 A secure, scalable online census system developed as my final-year BSc IT capstone project at Mount Kenya University. Awarded "Very Good & Impressive System" by supervising lecturer.  
 
 Key Features 
 - **Security-First Architecture**: Implemented CIA triad with RBAC, bcrypt hashing
- **Scalable 3-Tier Design**: Separation of presentation, logic, and data layers
- **Real-time Validation**: Client and server-side validation mechanisms
- **Admin Dashboard**: Comprehensive data management interface  ## Technologies Used - Backend: PHP, MySQL - Frontend: HTML5, CSS3, JavaScript - Security: Bcrypt, RBAC, Input Sanitization - Tools: XAMPP, Git
-  Security Implementation
    1. Role-Based Access Control (RBAC) Implemented four-tier user roles with granular permissions.        2. Data Protection - Bcrypt password hashing
       - Prepared statements to prevent SQL injection
       - Input validation and sanitization
    3. System Architecture Built using 3-tier architecture ensuring separation of concerns.
