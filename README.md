  📋 PROJECT OVERVIEW

A secure, scalable online census system designed to modernize traditional population data collection. Built as a final-year BSc IT capstone project with emphasis on security implementation, real-time validation, and enterprise-grade architecture.

This project demonstrates the practical application of cybersecurity principles in full-stack development, earning recognition for its robust security measures and innovative problem-solving approach.

   🔐 SECURITY IMPLEMENTATION Highlights

- CIA Triad Application: Confidentiality, Integrity, Availability model implemented end-to-end

- Role-Based Access Control (RBAC): 3-tier permission system (Citizen, user, Admin)

- Bcrypt Password Hashing

- SQL Injection Prevention: Prepared statements with parameterized queries

- Secure Session Management: Session regeneration, timeout enforcement

- Audit Logging: Comprehensive trail of all system actions

   🏗️ SYSTEM ARCHITECTURE

Three-Tier Architecture:
- Presentation Layer: HTML5, CSS3, JavaScript (Responsive Design)

- Application Layer: PHP (Business Logic & Security Controls)

- Data Layer: MySQL (Normalized Database with Indexing)
